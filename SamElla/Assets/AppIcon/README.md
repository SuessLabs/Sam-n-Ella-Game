# Application icon

Sam and Ella share a pixel-art badge in teal, purple, navy, and gold.

- `app-icon.png` is the original generated artwork with transparent corners.
- `app.ico` contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel frames.
- The project embeds the ICO into both managed and Native AOT executables.
- The game window loads the embedded large and small icons at system icon sizes.
- Velopack uses the same ICO for the installer and package.
- Source artwork and icon files are excluded from the runtime content folder.

Generated with the built-in ImageGen tool. ICO conversion preserves the source PNG and its alpha channel.

## Original generation prompt

Create one production-ready Windows application icon for a retro pixel-art side-scrolling platform game featuring Sam and Ella. Square 1:1 composition. A bold, compact pixel-art badge: two expressive blocky adventurer heads side by side, Sam on the left wearing a teal cap, Ella on the right wearing a purple cap with a dark purple ponytail. Warm peach faces, dark navy outlines, simple white eyes. Match authentic chunky 16-bit game sprite art with crisp square pixel clusters and a deliberately limited palette, not smooth vector illustration. Their heads fill most of a deep midnight-navy rounded pixel-square tile, with a thin warm-gold pixel border and a tiny brick ledge at its bottom. Strong clear silhouette readable at 32x32; generous large shapes and very little interior detail. The badge is centered and fills about 90 percent of the canvas. Actual transparent background outside the badge, including the corners. Flat front-facing composition, no perspective, no gradients, no shadows outside the tile, no text, no letters, no words, no watermark, no mockup, no extra objects, no icon sheet.
